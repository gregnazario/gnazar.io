macOS package management is fragmented: every language ecosystem ships its own
manager, and keeping global tools up to date means remembering a dozen
different commands. gimme is a single orchestration layer on top of all of
them — it does not replace Homebrew, Cargo, or npm, it coordinates them.

Built in Swift as a native CLI, it treats each underlying manager as a plugin
so new ecosystems can be added without changing the core.
