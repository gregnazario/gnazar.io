A set of example games built on Aptos, written to show what full-stack
on-chain game development looks like: Move contracts for game state, a
TypeScript frontend, and wallet-based interactions. The tic-tac-toe demo is
deployed and playable.

These became a common reference point for developers building their first
on-chain application — one of the most-starred things I've shipped.
