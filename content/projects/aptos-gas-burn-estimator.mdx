Long-lived accounts on Aptos pay upkeep in gas, and it's easy not to notice
the meter running down. The estimator answers the runway question directly:
it fetches live account state from Aptos, models burn from historical
consumption stored in SQLite, and serves the result through an Express API
validated with Zod.

A lightweight vanilla-JS frontend ships in the same repo and deploys as a
static site, so checking an address's runway takes seconds.
