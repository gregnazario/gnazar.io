Understanding a dependency graph starts with the lockfile — whichever manager
happens to have written it. dep-tracker detects and parses bun, npm, pnpm, and
yarn lockfiles (with a fallback parser for format surprises), then serves a
local web visualization of the graph built on D3.

It runs entirely on your machine via Bun: prod-only versus full-graph modes,
custom force/radial/tree layouts, sidebar search, and auto-opens the browser
so `bun run src/cli/index.ts` is the whole workflow.
