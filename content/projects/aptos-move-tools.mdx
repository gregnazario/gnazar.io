Most Move tooling needs a full compiler toolchain. This suite parses Move on
Aptos with tree-sitter instead, so each tool stays fast and error-tolerant
with zero Move dependencies installed: move-suggest lints for idiomatic Move 2,
move-bounds-checker catches Aptos VM limit violations before deployment,
move1-to-move2 automates syntax migration, and companions recover named
addresses or analyze gas usage.

For cases that need compiler-grade fidelity, move-bounds-checker-native plugs
into the legacy Move parser's checkout, trading convenience for accuracy.
